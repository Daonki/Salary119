# 🚨 급여119

임금체불 피해자를 위한 **법령 RAG 기반 AI 대응 서비스**

> 2026 법령데이터 활용 공모전 출품작 · 1인 개발

---

## 📌 서비스 소개

임금체불 피해를 입은 근로자는 관련 법령, 받을 수 있는 금액, 진정서 작성 방법, 찾아가야 할 기관을 혼자 알아봐야 합니다.
**급여119**는 피해 상황을 입력하면 관련 법 조문을 찾아 대응 방법을 안내하고, 체불 금액 계산부터 서식 작성, 기관 연계까지 4단계로 돕습니다.

| 단계 | 기능 | 설명 |
|---|---|---|
| 1 | 상황 입력 · 법령 검색 | 피해 상황과 가장 관련 있는 법 조문을 찾고, 그 조문을 근거로 AI가 대응 가이드 작성 |
| 2 | 체불 금액 계산 | 미지급 임금, 주휴수당, 퇴직금, 지연이자를 계산 |
| 3 | 서식 자동 생성 | 진정서·내용증명 초안을 생성하고 텍스트 파일로 다운로드 |
| 4 | 기관 연계 안내 | 진행 단계별 연계 기관과 준비 체크리스트, 지역별 관할 노동청 안내 |

## 🧠 RAG 구조

```
법제처 Open API ──▶ 조문 단위 청킹 ──▶ 임베딩 ──▶ 벡터 저장 (numpy)
  (5개 법령)          (299개 조문)     (1536차원)        │
                                                         ▼
사용자 질문 ──▶ 질문 임베딩 ──▶ 코사인 유사도 상위 k개 조문 ──▶ GPT-4o-mini 답변
```

1. **데이터 수집**: 법제처 Open API로 5개 법령의 조문 데이터를 JSON으로 수집
   - 근로기준법, 최저임금법, 근로자퇴직급여 보장법, 임금채권보장법, 소액사건심판법
2. **청킹**: 법령 JSON을 **조문 단위**로 나누고, 조문 안의 항·호를 하나의 텍스트로 병합 (목차 역할의 "전문" 항목은 제외)
3. **임베딩**: `text-embedding-3-small`로 299개 조문을 1536차원 벡터로 변환 (20개씩 배치 요청)
4. **검색**: 벡터 DB 라이브러리 없이 **numpy로 코사인 유사도 검색을 직접 구현**, 상위 조문을 근거로 사용
5. **답변 생성**: 검색된 조문만 근거로 `gpt-4o-mini`가 답변 (temperature 0.3)
   - 프롬프트에 "법령에 없는 내용은 추측하지 말고, 전문적인 판단이 필요하면 노무사·법률구조공단 상담을 안내하라"는 지시를 넣어 근거 없는 답변을 줄임

---

## 🔧 문제 해결: 법령 API 응답 형식 정규화

법제처 API 응답은 구조가 일정하지 않았습니다.

- 항·호가 **1개면 객체(dict), 여러 개면 리스트(list)**로 옴
- 항 내용이 **리스트 안의 리스트**로 오는 경우도 있음

그래서 어떤 형태로 와도 **항상 리스트로 통일**한 뒤 항·호 내용을 하나의 문자열로 합치도록 정규화했고, 그 결과 5개 법령을 **299개의 일관된 조문 청크**로 만들었습니다.

## 📁 프로젝트 구조

```
Salary119/
├── src/
│   ├── app.py               # Streamlit 메인 화면 (4단계 흐름)
│   ├── data_collector.py    # 법제처 Open API로 법령 수집 → data/raw/
│   ├── vectordb_builder.py  # 조문 청킹 + 임베딩 → data/vectors/
│   ├── rag_pipeline.py      # 질문 임베딩, 유사 조문 검색, 답변 생성
│   ├── calculator.py        # 체불 금액 계산
│   ├── form_generator.py    # 진정서·내용증명 초안 생성
│   └── agency_guide.py      # 단계별 기관 안내, 지역별 노동청 정보
└── requirements.txt
```

`data/`와 `.env`는 Git에 올리지 않습니다.

## 🚀 실행 방법

```bash
# 1. 저장소 클론 및 패키지 설치
git clone https://github.com/Daonki/Salary119.git
cd Salary119
pip install -r requirements.txt

# 2. 프로젝트 루트에 .env 파일 생성
# OPENAI_API_KEY=sk-...
# LAW_OC=법제처 Open API 인증값(OC)

# 3. 법령 데이터 수집 → 벡터 생성 (최초 1회)
python src/data_collector.py
python src/vectordb_builder.py

# 4. 실행
streamlit run src/app.py
```

## ⚠️ 한계와 개선 방향

- **금액 계산은 참고용 간이 계산입니다.** 주휴수당은 한 주 기준으로, 퇴직금은 월급을 평균임금으로 근사해 계산합니다. 실제 청구 금액은 근로 형태와 기간에 따라 달라질 수 있습니다.
- 생성되는 진정서·내용증명은 **초안**이며 법률 자문을 대신하지 않습니다.
- 개선 방향: 검색 정확도 평가 데이터셋 구축, 판례·행정해석 데이터 추가, 질문을 검색용 키워드로 재구성하는 단계 추가
